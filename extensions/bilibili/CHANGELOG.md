# Bilibili Extension

## 0.2.0

### Minor Changes

- 6bace9c: 新增 B 站收藏夹插件，通过所选浏览器采集自己的公开和私密收藏夹，保存原生身份、文字资料和成员关系，并提供独立读取视图。支持有界分批与进度复核，不保存视频二进制。

### Patch Changes

- Updated dependencies [6bace9c]
  - @inkcre/core@0.4.5

## 0.1.0

- 新增自己的公开及私密收藏夹采集、原生身份与成员关系存储，以及独立读取视图。
- 通过所选浏览器的登录态执行普通 collection Job，支持有界分页和经边界复核的继续采集。
- 保存文字与元数据，不保存视频二进制。
