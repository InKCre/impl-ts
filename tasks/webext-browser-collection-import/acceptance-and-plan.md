# WebExt 验收与实施计划

> 2026-10-23 精简验收：按用户授权补全保存后重开编辑、离线维护、同库地址修正、排除规则继续编辑及关闭 UI 后后台推进。测试不再把强制重填密钥、地址禁用或联网失败禁止保存当成正确行为。执行结果在实施接续记录，不以构建通过替代。

2026-10-22，用户接受 ROI/Peer 审计并要求推进。连续实现与验证授权有效；不提交发布，不修改其他会话源码。此版替换旧领域事务/回执驱动的验收。

追加验收：Explain/Writing Assist/旧侧栏与浮栏/模型设置不再有 UI、消息处理或构建入口；用户既有数据保留迁移。设置页沿用原有灰底方角卡片、白底字段和 teal 主动作，在 1280px、390px 和深色条件下无横向溢出。Switch 使用 xs 并显示 ON/OFF，默认字体下不超过 64×24px，名称与 aria-checked 明确，可键盘切换并在刷新后保留。后续验证仅在后台 headless 进行，不启动可见浏览器或操作日常会话。

## 以用户结果判断

| 场景                 | 必须观察的结果                                                                                          | 接受的边界                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 独立配置与保存       | 自有 Peer 身份、设置和 UI；不借 client-web 源码/会话/代理，写入普通数据库协议                           | 异构能力可按合同委托，不要求所有能力都本地                          |
| 工具栏弹窗与图标     | 实际 browser action 弹窗宽度正常、无竖排按钮或横向溢出、设置可达；工具栏使用对应逻辑尺寸的 optical 素材 | 普通标签页截图不能替代原生 popup 尺寸检查；未验收的浏览器和主题单列 |
| 普通页面、SPA 与重访 | 实际已加载材料可读，内容变化更新 current，重访不机械新增一整套当前资料                                  | 同 profile 同地址是 best-effort 当前观察，不证明网站账户身份        |
| 主动保存、选区、附注 | 原文、出处、附注可区分，自动刷新不改写主动材料                                                          | 不承诺保存所有自动历史                                              |
| 本机中断、断网与重启 | 已接纳载荷仍在，绑定原目标，保留错误并能继续                                                            | 可能有重复或孤立图/字节，不要求 exactly-once 或全图回滚             |
| 根存在但写入未完成   | 不显示完整保存、不释放原载荷；恢复继续缺失材料与附注                                                    | 不建设每次 CRUD 的操作日志或通用补偿                                |
| 暂停、排除和撤权     | 后续未派发自动项停住；手动仍可发送，不被暂停队头挡住                                                    | 已派发不能保证取消，不删除已存信息                                  |
| 混合书签/历史导入    | 实际内容进入图；失效/登录项保留记录，时间正确；重跑复用可见结果                                         | 非原生数据库快照，部分成功；一个执行 owner                          |
| PDF                  | 新连接从普通图/Storage 读回同一原始字节；不可取得时明确结果                                             | 不保证所有登录 viewer 或无限体积                                    |
| 来源与凭据边界       | 保存内容不执行脚本；草稿/密码不自动采集；原站请求无数据库认证                                           | 使用常规平台/库控制，不做广泛安全审计                               |
| 迁移与兼容           | 真实旧配置/待办不静默丢失；Chromium 与 Firefox 核心旅程可用                                             | 构建不代替运行，未运行的范围明确保留                                |

先使用小批可控页面和导入样本，再对实际代表性页面验证覆盖。测试不估计生产发生率，不为采集概率先建遥测。平台权限的人工证据与测试 profile 预授予的数据路径证据分别记录。

## 实施顺序

本轮追加检查：编辑回填实际密钥并默认遮罩，只改名称也能保存；网络登记悬挂不影响本机读改；地址修正保留身份并恢复原待办；排除草稿跨过状态刷新不丢；关闭设置页后混合导入仍完成；登记失败不挡住普通材料读写；前三项暂时失败不饿死第四项；带登录组件的公开文章可导入，实际短登录页仍保留补采原因。保留原有认证拒绝、PDF 拒绝后原载荷重试和重启恢复旅程。

1. 删除本任务未发布的 Python 材料协议、表模型和专属测试，保留 Capture 等变更。领域改为普通图 CRUD；core 仅补现有 binary transport 的精确连接注入。不改 generated 契约。
2. 实现材料读/写、固定与 current 区分、原生记录复用；保留本机载荷直到完成。使用已有 DBAPIClient，不建通用事务/幂等平台。
3. 修复自动消息结构、手动优先、暂停/撤权、未发自动合并；允许正常取材重定向，适配解析/编码。以页面、SPA、重访和主动材料不变验证正常闭环。
4. 验证书签/历史预览、真实正文、部分失败、重跑和停止/继续；PDF 验证原始字节。用一例中断恢复和一例不完整根区分“待办未丢”与“误报成功”，不保留原事务故障矩阵。
5. 核对旧配置/待办和旧入口，完成两浏览器、共享 core 回归与文档/署名。仅用 Helium 隔离 profile 做 Chromium 验收，不启动 Chrome for Testing，不触碰日常浏览会话。

真实数据库测试只用唯一可销毁数据库；现有 helper 创建自己的库、PostgREST 和 tunnel 并清理，不修改 cluster roles 或共享库。所有失败、未运行与外部资料源缺口在任务状态记录，不能用首条切片代替最终范围。
