# peerCard

Displays one Peer using the same product and technical language. Name and
owner config are editable shared facts；online status comes from database-time lease filtering，
not an ad-hoc health endpoint。配置编辑使用与 SourceForm 相同的 schema 表单／JSON 草稿组合；
无法可视化呈现的 schema 仍可通过 JSON 编辑，只有当前草稿完成校验才可保存。
