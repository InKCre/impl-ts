# LogsViewer

Job 内嵌观测视图，复用 ObservationExplorer 和 Core 的统一查询接口，不直接访问 PostgreSQL 或选择外部供应商。

`jobId` 同时关联新结构化事件和历史 job.N 日志；默认窗口从创建前一小时延至结束后一小时，给不同 Peer 的时钟偏差留出余量。进行中的作业以刷新时间估算结束端。超过 31 天时显示末段，可在关联筛选选择更早的绝对窗口。也保留独立 `traceId` 查询。

查询有界，记录过多时提示缩窄范围；不承诺全量历史。`enablePolling` 与 `pollingInterval` 控制刷新。连接或业务范围变化使在途响应失效；刷新失败保留同范围已有记录并提示重试。

Job 页面从信息库中的 Job 行展示“提交已保存”、当前状态与创建、开始、结束时间。
这些信息可由其他 Peer 在提交方退出后读取。观测列表和摘要只消费实际返回的记录，
查询为空时仍显示该 Job 的持久信息。
